# reports/

This folder is populated automatically when you run the Kaggle notebook.

Download the following files from your Kaggle notebook output and place them here:

- `model_comparison.csv`     — PR-AUC, ROC-AUC, F1 comparison table
- `pr_curves.png`            — Precision-Recall curves for all 3 models
- `confusion_matrix.png`     — Confusion matrix for the best model on test set
- `feature_importance.png`   — Top feature importances

See README.md for instructions.
